One sentence about the best advice I ever received — my father's rule about never borrowing money for anything that loses value overnight, and how I still hear him twenty years later.

`main.py` writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, with no network access.
